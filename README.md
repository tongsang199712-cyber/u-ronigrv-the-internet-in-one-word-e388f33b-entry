The whole internet, in one word: **feral**.

The internet is not a library, a town square, or a shopping mall. It is a wild place that nobody owns, nobody tames, and everybody feeds — comment sections, reply guys, 3 a.m. rabbit holes, drama, memes, scams, brilliance, all running loose together. One word for that is "feral": funny on its own, true of the internet as a whole, and short enough to land in one beat.

## Run it

```sh
node main.ts
```

This writes exactly one word to `/output/entry.txt` (no trailing newline).
